### PythonでMIDIデータを自在に操る！作曲を自動化する第一歩

DTMにおけるMIDIデータは、楽曲の骨格となる非常に重要な要素です。Pythonを使えば、このMIDIデータをプログラムで生成したり、編集したりすることが可能になります。これにより、作曲のアイデア出しや、複雑なフレーズの生成などを効率化できます。

#### 1. MIDIデータの基本とPythonでの扱い方

MIDI（Musical Instrument Digital Interface）は、楽器の演奏情報をデジタルデータとしてやり取りするための規格です。音の高さ（ノート番号）、長さ、強さ（ベロシティ）、タイミングなどの情報を含みます。

PythonでMIDIデータを扱うには、`mido`というライブラリが便利です。このライブラリを使うと、以下のような操作が簡単に行えます。

*   **新しいMIDIファイルの作成:** 空のMIDIファイルを作成し、そこに音符情報を追加していくことができます。
*   **既存のMIDIファイルの読み込み・編集:** 既存のMIDIファイルを読み込み、特定の音符を削除したり、音色を変更したり、テンポを調整したりできます。
*   **音符の追加・削除・変更:** プログラムのロジックに基づいて、自由自在に音符を追加・削除・変更できます。

#### 2. アルゴリズム作曲の基礎：ランダムフレーズ生成

例えば、簡単なアルゴリズム作曲として、ランダムなメロディーラインを生成してみましょう。以下のPythonコードは、指定された音階の中からランダムに音を選び、一定の長さのMIDIフレーズを作成する例です。

```python
from mido import Message, MidiFile, MidiTrack
import random

# 使用する音階（Cメジャースケール）
scale = [60, 62, 64, 65, 67, 69, 71, 72] # MIDIノート番号（ドレミファソラシド）

# MIDIファイルとトラックの初期化
mid = MidiFile()
track = MidiTrack()
mid.tracks.append(track)

# テンポ設定 (BPM)
track.append(Message('set_tempo', tempo=500000)) # 120 BPM

# 生成する音符の数
num_notes = 16

# 音符を生成
current_time = 0
for _ in range(num_notes):
    note = random.choice(scale)
    velocity = random.randint(60, 100) # 強さ
    duration = random.choice([240, 480, 960]) # 長さ (tick単位)

    # Note On メッセージ
    track.append(Message('note_on', note=note, velocity=velocity, time=0))
    # Note Off メッセージ (duration後に発火)
    track.append(Message('note_off', note=note, velocity=velocity, time=duration))
    current_time += duration

# MIDIファイルを保存
mid.save('random_melody.mid')
print("random_melody.mid を生成しました。")
```

このコードでは、`random.choice()`を使って音階からランダムに音を選び、`random.randint()`で強さを、そしてランダムな`duration`で音の長さを決定しています。生成された`random_melody.mid`ファイルをDAWで読み込めば、AIが生成したかのようなメロディーが再生されます。

### サウンドデザインを効率化！Pythonでエフェクトを自動生成

音楽制作において、サウンドデザインは楽曲の個性を際立たせる重要な要素です。しかし、エフェクトの設定を細かく調整したり、複数のエフェクトを組み合わせたりするのは、時間のかかる作業でもあります。Pythonを使えば、これらのサウンドデザインプロセスを自動化・効率化することが可能です。

#### 1. オーディオ信号処理の基本とPythonライブラリ

Pythonでオーディオ信号を処理するには、`librosa`や`pydub`といったライブラリがよく利用されます。これらのライブラリを使うことで、以下のようなことが可能になります。

*   **オーディオファイルの読み込み・書き出し:** WAVやMP3などのオーディオファイルを読み込み、Python上で波形データを操作できます。
*   **基本的なエフェクト処理:** 音量の調整、フェードイン・フェードアウト、ノイズ除去などの基本的なエフェクトをプログラムで適用できます。
*   **FFT（高速フーリエ変換）:** 音声信号を周波数成分に分解し、より高度なエフェクト処理や解析の基盤となります。

#### 2. アルゴリズムによるエフェクト生成：リバーブやディレイの自動調整

例えば、複数のオーディオファイルに対して、一律の残響（リバーブ）を適用したい場合を考えてみましょう。DAW上では一つずつ設定する必要がありますが、Pythonスクリプトを使えば、一括で処理できます。

```python
from pydub import AudioSegment
import os

def apply_reverb_batch(input_dir, output_dir, dry_wet_mix=0.5, room_scale=0.5):
    """
    指定されたディレクトリ内のオーディオファイルにリバーブを適用し、別ディレクトリに保存する関数
    (pydub単体では高度なリバーブは難しいですが、概念的な例として)
    """
    for filename in os.listdir(input_dir):
        if filename.endswith(".wav"): # WAVファイルのみを対象とする
            input_path = os.path.join(input_dir, filename)
            output_path = os.path.join(output_dir, filename)

            audio = AudioSegment.from_wav(input_path)

            # ここでリバーブ処理を模倣する（pydub単体では簡易的なものになる）
            # 実際には、より高度なオーディオ信号処理ライブラリや、DAW連携が必要になる場合が多い
            # 例：音量を少し小さくし、ディレイをかけるようなイメージ
            delayed_audio = audio.apply_gain(0.8).fade_out(duration=1000) # 簡易的なディレイとフェードアウト
            processed_audio = audio.overlay(delayed_audio, gain_during_overlay=-6, position=500) # 音量調整して重ねる

            processed_audio.export(output_path, format="wav")
            print(f"{filename} にリバーブ（簡易版）を適用し、{output_path} に保存しました。")

# 使用例
input_directory = "audio_files" # 元のオーディオファイルがあるディレクトリ
output_directory = "processed_audio_files" # 処理後のファイルを保存するディレクトリ

# ディレクトリが存在しない場合は作成
if not os.path.exists(output_directory):
    os.makedirs(output_directory)

apply_reverb_batch(input_directory, output_directory)
```

この例では、`pydub`を使ってオーディオファイルを読み込み、簡易的なエフェクト処理（ここではディレイとフェードアウトをリバーブのイメージとして使用）を施し、別のディレクトリに保存しています。実際には、より高度なリバーブやディレイ、その他のエフェクトを実装するには、`scipy`や`numpy`といった数値計算ライブラリと組み合わせて、より複雑な信号処理を行う必要があります。

#### 2. 定型作業の自動化：バックアップスクリプトの例

定期的なプロジェクトのバックアップは、データ消失のリスクを回避するために非常に重要です。しかし、手作業で行うのは忘れがちです。以下のようなPythonスクリプトで、プロジェクトフォルダのバックアップを自動化できます。

```python
import os
import shutil
import datetime

def backup_project(project_path, backup_dir):
    """
    指定されたプロジェクトフォルダをバックアップディレクトリにコピーする関数
    """
    if not os.path.exists(project_path):
        print(f"エラー: プロジェクトパス '{project_path}' が存在しません。")
        return

    if not os.path.exists(backup_dir):
        os.makedirs(backup_dir)

    # バックアップファイル名に日付と時刻を追加
    timestamp = datetime.datetime.now().strftime("%Y%m%d_%H%M%S")
    backup_folder_name = f"backup_{timestamp}"
    backup_destination = os.path.join(backup_dir, backup_folder_name)

    try:
        shutil.copytree(project_path, backup_destination)
        print(f"プロジェクト '{project_path}' を '{backup_destination}' にバックアップしました。")
    except Exception as e:
        print(f"バックアップ中にエラーが発生しました: {e}")

# 使用例
project_to_backup = "/path/to/your/DAW_Project" # 実際のプロジェクトパスに置き換えてください
backup_location = "/path/to/your/backup_folder" # バックアップを保存する場所を指定してください

backup_project(project_to_backup, backup_location)
```

このスクリプトを実行すると、指定したプロジェクトフォルダが、日付と時刻を付与された新しいフォルダとしてバックアップ先にコピーされます。さらに、このスクリプトをタスクスケジューラ（Windows）やcron（macOS/Linux）と連携させれば、毎日決まった時間に自動でバックアップを実行することも可能です。
