### 楽譜自動生成の基礎：Pythonで音楽を「記述」する

楽譜自動生成の第一歩は、Pythonを使って音楽の要素をデータとして表現することです。音楽は、音の高さ（ピッチ）、長さ（デュレーション）、強さ（ベロシティ）、そしてそれらがどのように組み合わさるか（リズム、ハーモニー）といった要素で構成されています。Pythonでは、これらの要素を数値や文字列として扱い、プログラム上で音楽を「記述」していきます。

楽譜を生成するための代表的なPythonライブラリとして、「**music21**」が挙げられます。music21は、音楽理論、分析、生成、そして楽譜の作成といった幅広い機能を提供しています。このライブラリを使えば、音符、コード、拍子記号、調号などをオブジェクトとして扱い、それらを組み合わせて楽曲を構築していくことができます。

例えば、簡単なメロディーを生成するコードは以下のようになります。

```python
from music21 import note, stream

# 新しいストリーム（楽譜の断片）を作成
s = stream.Stream()

# ドの音符を作成 (ピッチ='C', 長さ='quarter' = 四分音符)
note_c = note.Note('C', quarterLength=1.0)
s.append(note_c)

# レの音符を作成
note_d = note.Note('D', quarterLength=1.0)
s.append(note_d)

# ミの音符を作成
note_e = note.Note('E', quarterLength=1.0)
s.append(note_e)

# 生成したストリームを表示（簡易的なテキスト表示）
s.show('text')

# MIDIファイルとして保存（別途MIDI再生環境が必要）
# s.write('midi', fp='simple_melody.mid')
```

このコードを実行すると、ド、レ、ミの音符が順番に並んだシンプルなメロディーが生成されます。`note.Note()` の引数で音名と長さを指定することで、様々な音符を表現できます。`stream.Stream()` は、これらの音符を時系列に並べるための「流れ」のようなものです。

### リズムとハーモニーの自動生成：作曲に深みを与える

単音のメロディーだけでなく、音楽に深みを与えるリズムやハーモニーを自動生成することも、Pythonを使えば可能です。

#### リズムパターンの生成

リズムは、音楽の躍動感やグルーヴを生み出す重要な要素です。Pythonでは、ランダム性を取り入れたり、特定の音楽的規則に基づいたりして、多様なリズムパターンを生成できます。

例えば、四分音符と八分音符をランダムに組み合わせてリズムを生成するコードは以下のようになります。

```python
import random
from music21 import note, stream, meter

# 新しいストリームと拍子記号を設定
s = stream.Stream()
s.append(meter.TimeSignature('4/4')) # 4/4拍子

# 生成する音符の数
num_notes = 8

# 音符の長さの候補（四分音符、八分音符）
durations = [1.0, 0.5] # 1.0 = 四分音符, 0.5 = 八分音符

for _ in range(num_notes):
    # ランダムに音符の長さを選択
    selected_duration = random.choice(durations)
    # ダミーの音符を作成（ここではピッチは固定）
    n = note.Note('C', quarterLength=selected_duration)
    s.append(n)

s.show('text')
```

このコードでは、`random.choice()` を使って、あらかじめ定義した音符の長さのリストからランダムに一つを選択し、それを繰り返しています。これにより、予測不可能な、しかし音楽的なリズムパターンを生成できます。

#### ハーモニー（和音）の生成

ハーモニーは、音楽に色彩感や感情的な深みを与えます。music21ライブラリは、コード（和音）を扱う機能も豊富に備えています。例えば、基本的な三和音（メジャーコード、マイナーコード）を生成したり、コード進行を自動生成したりすることが可能です。

```python
from music21 import chord, stream, meter

s = stream.Stream()
s.append(meter.TimeSignature('4/4'))

# Cメジャーコードを作成
c_major = chord.Chord(['C4', 'E4', 'G4'])
c_major.quarterLength = 4.0 # 4分音符の長さ
s.append(c_major)

# Gメジャーコードを作成
g_major = chord.Chord(['G4', 'B4', 'D5'])
g_major.quarterLength = 4.0
s.append(g_major)

# Amマイナーコードを作成
a_minor = chord.Chord(['A4', 'C5', 'E5'])
a_minor.quarterLength = 4.0
s.append(a_minor)

s.show('text')
```

ここでは、`chord.Chord()` に音名のリストを渡すことで、和音を表現しています。これにより、コード進行をプログラミングで記述し、音楽に厚みを持たせることができます。

国内の音楽系スタートアップ企業によるレポートでは、AIを活用したコード生成技術が、既存の楽曲の雰囲気を保ちつつ、新たなハーモニーを提案するツールとして、作曲家から高い評価を得ているとのことです。Pythonとmusic21を使えば、このような高度なハーモニー生成の基礎を自分で構築することも夢ではありません。

### より高度な楽譜生成：音楽理論とアルゴリズムの活用

ここまでの基本テクニックに加えて、音楽理論やアルゴリズムを組み合わせることで、さらに複雑で独創的な楽譜を自動生成することが可能になります。

#### 音楽理論に基づいた生成

音楽理論には、スケール（音階）、モード、カデンツ（終止形）、対位法など、楽曲の構造を理解し、構築するための様々なルールが存在します。Pythonとmusic21を使えば、これらの音楽理論をプログラムに落とし込み、理論的に正しい、あるいは意図した効果を持つ音楽を生成できます。

例えば、特定のスケール内でのみ音符を生成する、といった制約を設けることで、より統一感のあるメロディーラインを作ることができます。

#### アルゴリズム作曲

アルゴリズム作曲とは、数学的なアルゴリズムや、乱数、フラクタル図形、セルオートマトンといった計算論的な手法を用いて音楽を生成するアプローチです。これにより、人間が通常思いつかないような、複雑で有機的な音楽構造を生み出すことができます。

例えば、**マルコフ連鎖**という確率モデルは、ある状態（例えば、直前に鳴った音）に基づいて次の状態（次の音）を予測するのに使われます。これを音楽に応用することで、ある程度音楽的な「つながり」を持ちつつも、予測不可能なメロディーを生成することができます。

```python
import random
from music21 import note, stream, meter

# マルコフ連鎖の例（簡易版）
# 遷移確率: C -> D, D -> E, E -> C
transitions = {
    'C': {'D': 0.7, 'E': 0.3},
    'D': {'E': 0.6, 'C': 0.4},
    'E': {'C': 0.8, 'D': 0.2}
}

# 現在の音
current_note_name = 'C'
# scale = ['C', 'D', 'E', 'F', 'G', 'A', 'B'] # 簡単なスケール（今回は使用しない）

s = stream.Stream()
s.append(meter.TimeSignature('4/4'))
s.append(note.Note('C4', quarterLength=0.5)) # 開始音

num_steps = 20 # 生成する音符の数

for _ in range(num_steps):
    # 次の音を確率に基づいて選択
    possible_next_notes = transitions[current_note_name]
    next_note_options = list(possible_next_notes.keys())
    probabilities = list(possible_next_notes.values())

    # random.choicesでk=1を指定するとリストが返るため、[0]で要素を取り出す
    next_note_name = random.choices(next_note_options, weights=probabilities, k=1)[0]

    # 音符を作成（ここでは長さは固定）
    n = note.Note(next_note_name + '4', quarterLength=0.5)
    s.append(n)
    current_note_name = next_note_name # 現在の音を更新

s.show('text')
```

このコードは、前述のマルコフ連鎖の考え方を簡易的に実装したものです。直前の音に応じて、次の音が鳴る確率が設定されており、それに基づいてランダムに音を選択しています。これにより、単なるランダム生成よりも、より音楽的なフレーズを生成することが期待できます。

学術研究によれば、このようなアルゴリズム作曲は、人間の作曲家が持つ潜在的な創造性を引き出し、全く新しい音楽ジャンルやスタイルを生み出す可能性を秘めているとされています。例えば、Google Magentaプロジェクトのような先進的な研究開発では、深層学習と組み合わせた高度な音楽生成モデルが開発されており、その進化は目覚ましいものがあります。
