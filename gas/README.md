| 列A | 列B | 列C | 列D | 列E | 列F |

| item | stock | remark | notice | noticeDate | noticeTime |
| 商品名 | 在庫数 | 備考 | お知らせ本文 | 表示開始日 | 表示開始時刻 |

## デプロイ手順

1. [Google Apps Script エディタ](https://script.google.com) を開く
2. 新しいプロジェクトを作成
3. `Code.gs` の内容を貼り付け
4. 右上の「デプロイ」→「新しいデプロイ」をクリック
5. 種類を「ウェブアプリ」に設定
6. 以下の設定を行う：
   - **説明**: 在庫情報API（任意）
   - **次のユーザーとして実行**: 自分
   - **アクセスできるユーザー**: 全員
7. 「デプロイ」をクリック
8. 表示されたウェブアプリURLをコピー
9. `test.js` の `STOCK_URL` を新しいURLに更新

## 動作確認

- ブラウザで `https://your-deployment-url/exec` にアクセスしてJSONが返ることを確認
- JSONP対応確認: `https://your-deployment-url/exec?callback=test` でJavaScript形式が返ることを確認

## お知らせ機能の仕様

- **表示条件**: `noticeDate` + `noticeTime` で指定した日時から60分間表示
- **非表示**: ユーザーが×ボタンで閉じると、同じ内容は再表示されない
- **複数お知らせ**: 複数の行が条件に合う場合、最初の1件のみ表示

## トラブルシューティング

### データが表示されない
- スプレッドシートIDとシート名が正しいか確認
- Apps Scriptのアクセス権限が「全員」になっているか確認
- ブラウザのコンソール（F12）でエラーを確認

### お知らせが表示されない
1. ブラウザのコンソールで `[stock] first row sample:` を確認
2. `notice`, `noticeDate`, `noticeTime` が正しく取得できているか確認
3. 日付・時刻が現在時刻から60分以内か確認
4. フォーマット: 日付は `YYYY-MM-DD`、時刻は `HH:MM`（24時間形式）

### 日付・時刻のフォーマット例
- スプレッドシートのセル形式は「日付」「時刻」に設定推奨
- 手入力する場合: `2025-12-04` `15:30`
